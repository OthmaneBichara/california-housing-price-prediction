California Housing Price Prediction

A beginner-friendly machine learning project predicting California housing values using the California Housing dataset.

Models

Linear Regression

Random Forest Regressor

Regularized Random Forest

Evaluation

Models are evaluated using R² and Root Mean Squared Error (RMSE).

Tools

Python, Pandas, NumPy, Matplotlib, Scikit-learn, Statsmodels, Google Colab

Status

Initial version — further analysis and improvements planned.
